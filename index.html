🔄 find_rotation_center

같은 장면을 서로 다른 각도로 찍은 영상 두 장만 있으면, 영상 처리로 회전각과 회전중심 좌표를 역산할 수 있습니다. 카메라·스테이지 캘리브레이션에서 회전축 위치를 실측 없이 영상만으로 구할 때 쓰는 기법입니다.

정밀도 분석 리포트

노이즈가 있을 때 1쌍 vs 여러 장 사용 시 정밀도가 얼마나 달라지는지 몬테카를로로 검증했습니다.

 💻

소스 코드 (GitHub)

Python 구현체, 시뮬레이션 스크립트, 원시 데이터를 모두 확인할 수 있습니다.

어떻게 동작하나요

1. 각도 탐색-10°~10° 범위를 성기게, 그다음 촘촘하게 훑으며 최적 회전각 후보를 찾습니다.
2. 평행이동 정합후보 각도마다 두 영상이 가장 잘 겹치는 평행이동을 정규상관으로 찾습니다.
3. 최적 후보 선택정합 점수(NCC)가 가장 높은 각도·평행이동 조합을 채택합니다.
4. 중심 역산회전각과 평행이동으로부터 연립방정식을 풀어 회전중심 좌표를 구합니다.

정밀도는 어느 정도인가요

노이즈 없는 이상 조건
~0.05 px
현실적 카메라 노이즈, 1쌍
~2.6 px
노이즈 + 서로 다른 각도 12장
~0.56 px
회전각 정밀도 바닥
~0.01~0.02°

핵심 발견: 회전중심을 정밀하게 구하려면 몇 장을 찍느냐보다 어떤 각도 조합으로 찍느냐가 더 중요합니다. 같은 각도를 반복 촬영하면 개선폭이 제한적이지만, 3~8° 범위에서 서로 다른 각도로 여러 장을 찍어 결합하면 4배 이상 정밀해집니다. 전체 방법론과 노이즈 비교 이미지는 정밀도 분석 리포트에서 확인할 수 있습니다.
